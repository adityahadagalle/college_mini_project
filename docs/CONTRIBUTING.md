# 🤝 Contributing Guidelines

Thank you for considering contributing to SentimentAI Enterprise! We welcome contributions from developers, researchers, and designers.

---

## 📜 Code of Conduct

Please maintain professional, courteous, and respectful communication across all discussions, issues, and pull requests.

---

## 🛠️ How to Contribute

1. **Fork the Repository** on GitHub.
2. **Create a Feature Branch**: `git checkout -b feature/my-amazing-feature`.
3. **Commit your changes**: `git commit -m 'feat: Add amazing new feature'`.
4. **Run Quality Gates**: Ensure all tests, Mypy strict checks, and linter checks pass cleanly.
5. **Push to GitHub**: `git push origin feature/my-amazing-feature`.
6. **Open a Pull Request** against the `main` branch.

---

## 📐 Commit Message Convention

Follow standard Conventional Commits formatting:
- `feat: ...` for new features.
- `fix: ...` for bug fixes.
- `docs: ...` for documentation changes.
- `test: ...` for test additions or updates.
- `refactor: ...` for code improvements without functional changes.
