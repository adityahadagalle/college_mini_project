# 📸 Screenshot Capture & Asset Guide

To showcase SentimentAI Enterprise on your GitHub README and portfolio, capture the following 5 high-resolution screenshots from the running local application (`http://localhost:5173`).

---

## 📌 Required Screenshots List

| Screenshot File Name | Page / Tab | Visual Action to Capture |
| :--- | :--- | :--- |
| `01_predict_xai.png` | **Real-Time Prediction** | Type a review and press Ctrl+Enter. Show prediction results, float confidence score bars, and **inline token gradient heatmap**. |
| `02_batch_ingestion.png` | **Batch Processing** | Upload a CSV file and capture the live streaming progress bar (1,000+ items/sec throughput). |
| `03_analytics_dashboard.png` | **Executive Analytics** | Display the dark-mode Recharts sentiment trends, ratio pie charts, and confidence distribution. |
| `04_mlops_registry.png` | **MLOps & Registry** | Display the model version table, active model badge, and rollback action drawer. |
| `05_history_table.png` | **Prediction History** | Show the sortable historical Explorer table with sentiment badges and CSV export button. |
